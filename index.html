Сначала установите приложение

На iPhone уведомления приходят только из приложения, добавленного на экран «Домой». Из Safari они не работают — это ограничение Apple.

  1. Нажмите Поделиться — квадрат со стрелкой вверх внизу экрана
  2. Выберите На экран «Домой»
  3. Нажмите Добавить
  4. Откройте Регмонитор с экрана «Домой» и вернитесь сюда
